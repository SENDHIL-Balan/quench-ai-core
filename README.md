# Bravura AI

BRAVURA AI — REAL WORKING BASE AI AGENT + LIVE TWO-WAY VOICE AGENT

1. The frontend features a sleek cosmic futuristic dark theme with live two-way conversational voice.
2. The application contains a real AI agent that can receive a user prompt, reason about it, and return an actual AI-generated response.
3. Live Voice Agent enables hands-free continuous real-time voice conversations.
4. Extensible multi-provider architecture supporting Gemini, Groq, and OpenAI models.

==================================================

CORE CAPABILITIES

==================================================

1. Open Bravura AI.
2. Type a prompt or upload attachments (PDF, TXT, Markdown, CSV, JSON).
3. Toggle Deep Think and Web Search.
4. Real-time Voice to Text transcription.
5. Real-time Live Voice Agent: talk in live two-way voice with Bravura AI.
6. Select a mode (Chat, Research, Create, Analyze, Code, Image).
7. Fast streaming AI responses with real agent status (Idle, Thinking, Generating, Complete).
